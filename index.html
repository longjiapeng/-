第一章 · 计算机系统概论  |  第二章 · 开关理论基础

第一章 计算机系统概论 硬件与软件

1.1 计算机系统基本组成

计算机系统 = 硬件 + 软件

  • 硬件：CPU、内存、硬盘、键盘、显示器等物理设备
  • 软件：程序 + 文档，分为系统软件和应用软件

冯·诺依曼五大部件：

  1. 运算器 —— 算术/逻辑运算
  2. 控制器 —— 指挥协调
  3. 存储器 —— 存放程序和数据
  4. 输入设备 —— 接收外部信息
  5. 输出设备 —— 输出结果
核心特点：存储程序、程序控制
例题 冯·诺依曼结构核心思想
现代计算机普遍采用冯·诺依曼结构，它的核心思想是什么？
1冯·诺依曼结构的关键在于"存储程序"——把程序像数据一样存进存储器。
2计算机按顺序从存储器中取出指令并执行，即"程序控制"。
3因此五大部件（运算器、控制器、存储器、输入、输出）以运算器为中心协同工作。
4现代机器已改为以存储器为中心，但存储程序思想不变。
1 冯·诺依曼计算机中，指令和数据都存放在哪里？
2 冯·诺依曼结构的核心思想是________和程序控制。（填四个字）
1.2 计算机硬件组成
  • CPU = 运算器 + 控制器
    • 运算器：ALU、寄存器、累加器
    • 控制器：PC、IR、时序电路、微操作信号发生器
  • 存储器：主存（内存）、辅存（外存）
  • 总线：数据总线、地址总线、控制总线

主机 = CPU + 主存 外设 = 输入/输出/外存

例题 CPU 的组成
CPU 由哪两大部分组成？各自的功能是什么？
1CPU = 运算器 + 控制器。
2运算器负责算术运算（加减乘除）和逻辑运算（与或非），核心部件是 ALU。
3控制器负责指挥协调，包含 PC（程序计数器）、IR（指令寄存器）等。
1以下哪个部件不属于 CPU？
2PC 的中文名称是________。
1.3 计算机软件
分类说明举例
系统软件管理硬件、支持应用操作系统、编译程序
应用软件解决具体问题Word、浏览器

语言层次：机器语言 → 汇编语言 → 高级语言

翻译程序：

  • 汇编程序：汇编语言 → 机器语言
  • 编译程序：高级语言 → 机器语言（整体翻译）
  • 解释程序：高级语言 → 逐句解释执行
例题 编译 vs 解释
编译程序和解释程序的主要区别是什么？
1编译程序：把整个高级语言源程序一次性翻译成机器语言目标程序，再执行。
2解释程序：逐句翻译并立即执行，不生成目标程序。
3编译方式执行速度快，解释方式灵活、便于调试。
1以下哪个属于系统软件？
1.4 计算机的工作过程
  1. 取指令（PC → 地址 → 取指令 → IR）
  2. 分析指令（译码）
  3. 执行指令
  4. 更新PC，准备下一条

指令周期 > 机器周期 > 时钟周期

例题 指令执行流程
请按顺序说明一条指令的执行过程。
1取指令：PC 提供地址，从存储器取出指令送入 IR。
2分析指令：对 IR 中的指令进行译码，确定操作类型。
3执行指令：由控制器发出控制信号，完成操作。
4更新 PC：PC 自动加 1，指向下一条指令。
1指令周期、机器周期、时钟周期三者的关系是？
1.5 主要性能指标
指标含义
机器字长CPU一次能处理的二进制位数
主频时钟频率，单位 Hz
存储容量主存能存放的字节数
运算速度MIPS、CPI、FLOPS
吞吐量单位时间完成的任务量
响应时间从请求到结果的时间

CPU时间 = 指令数 × CPI × 时钟周期 MIPS = 指令数 / (执行时间 × 10⁶)

例题 CPU 时间计算
某程序共 10⁶ 条指令，CPI = 2，时钟频率 = 1 GHz，求 CPU 执行时间。
1时钟周期 = 1 / 时钟频率 = 1 / (1×10⁹) = 1 ns
2CPU 时间 = 指令数 × CPI × 时钟周期
3= 10⁶ × 2 × 1 ns = 2 × 10⁶ ns = 2 ms
1 某程序 10⁶ 条指令，CPI = 1，时钟频率 500 MHz，CPU 执行时间为________ms。
1.6 计算机分类与发展
  • 按规模：巨型机、大型机、小型机、微型机
  • 按用途：通用机、专用机
  • 发展代际：电子管 → 晶体管 → 集成电路 → 超大规模集成电路
摩尔定律：集成电路上晶体管数目约每18-24个月翻一番。
例题 摩尔定律
什么是摩尔定律？它对计算机发展有什么影响？
1摩尔定律：集成电路上可容纳的晶体管数目约每 18-24 个月翻一番。
2它推动了计算机性能的快速提升和成本的持续下降。
3也是"微型机"能不断更新换代的理论基础。
1计算机发展的第一代主要采用什么元器件？

第二章 开关理论基础 逻辑代数与门电路

2.1 数字逻辑基础
  • 数字信号 vs 模拟信号：数字信号离散（0/1）；模拟信号连续变化
  • 正逻辑：高电平 = 1，低电平 = 0
  • 负逻辑：高电平 = 0，低电平 = 1
例题 正逻辑与负逻辑
同一个电平信号，在正逻辑和负逻辑下对应的值有什么不同？
1正逻辑：高电平 = 1，低电平 = 0。
2负逻辑：高电平 = 0，低电平 = 1。
3同一个物理电平在两种逻辑下表示的值是相反的，但电路本身并没有变。
1若规定高电平表示 0，低电平表示 1，这种逻辑称为________。
2.2 逻辑代数（布尔代数）

三种基本运算：

运算符号表达式口诀
与· / ∧Y = A·B全1才1
或+ / ∨Y = A+B有1就1
非′ / ¬Y = A′取反

复合运算：

  • 与非：Y = (A·B)′
  • 或非：Y = (A+B)′
  • 异或：Y = A⊕B = A′B + AB′
  • 同或：Y = A⊙B = AB + A′B′
例题 异或运算
A = 1，B = 0，求 A⊕B 的值。
1异或定义：A⊕B = A′B + AB′
2代入 A=1，B=0：A′B = 0·0 = 0，AB′ = 1·1 = 1
3所以 A⊕B = 0 + 1 = 1
4口诀记忆：不同出 1，相同出 0。
1当 A = 1，B = 1 时，A⊕B 的值为________。
2当 A = 1，B = 0 时，A⊙B（同或）的值为________。
2.3 逻辑代数基本定律
定律与形式或形式
交换律A·B = B·AA+B = B+A
结合律(AB)C = A(BC)(A+B)+C = A+(B+C)
分配律A(B+C)=AB+ACA+BC=(A+B)(A+C)
吸收律A+AB=AA(A+B)=A
摩根定律(AB)′=A′+B′(A+B)′=A′·B′

A + A′ = 1 A · A′ = 0 A + 1 = 1 A · 0 = 0

例题 摩根定律应用
化简 (A·B)′ 并写出等价表达式。
1摩根定律第一种形式：(A·B)′ = A′ + B′
2口诀记忆："与变或，各自非"。
3第二种形式：(A+B)′ = A′·B′，口诀："或变与，各自非"。
1根据摩根定律，(A·B)′ = ________。（用 A、B、′、+ 表示）
2根据吸收律，A + AB = ?
2.4 逻辑函数的表示方法
  1. 真值表 —— 穷举输入输出
  2. 逻辑表达式 —— 代数式
  3. 逻辑图 —— 门电路连接图
  4. 卡诺图 —— 方格图化简
  5. 波形图 —— 时序变化

标准形式：

  • 最小项：每个变量以原/反形式出现一次，如 A′BC
  • 最大项：每个变量以原/反形式出现一次，如 A+B′+C
  • 最小项之和 = 标准与或式；最大项之积 = 标准或与式
例题 最小项
三变量 A、B、C 中，A′BC 是不是最小项？为什么？
1最小项要求每个变量都以原或反形式出现一次且仅一次。
2A′BC 中 A 以反形式出现，B 和 C 都以原形式出现，各一次。
3所以 A′BC 是最小项。
1以下哪个是三变量 A、B、C 的最小项？
2.5 逻辑函数化简

代数化简法：

  • 并项法：AB + AB′ = A
  • 吸收法：A + AB = A
  • 消去法：A + A′B = A + B
  • 配项法：A = A(B+B′)

卡诺图化简法：

  • 相邻格只有一位变化
  • 圈越大越好，圈数越少越好
  • 每个圈包含 2ⁿ 个 1
  • 圈可以重叠，但每个圈要有新 1
  • 无关项可圈可不圈
例题 代数化简
化简 Y = AB + AB′。
1提取公因式 A：Y = A(B + B′)
2由互补律：B + B′ = 1
3所以 Y = A · 1 = A
4这就是并项法——两项合并成一项。
1化简 Y = A + A′B，结果为________。
2.6 门电路基础
门符号功能
与门AND全1出1
或门OR有1出1
非门NOT取反
与非门NAND全1出0
或非门NOR有1出0
异或门XOR不同出1
同或门XNOR相同出1

TTL vs CMOS：

  • TTL：双极型，速度快，功耗大
  • CMOS：单极型，功耗低，抗干扰强
例题 与非门
当输入端 A = 1，B = 1 时，与非门输出什么？
1与非门 = 与门 + 非门。
2先做与运算：1 · 1 = 1。
3再取反：1′ = 0。
4口诀：与非门全 1 出 0。
1或门输入端 A = 0，B = 1，输出为________。
2与非门输入端 A = 1，B = 0，输出为________。
2.7 组合逻辑电路初步

分析步骤：逻辑图 → 表达式 → 真值表 → 功能

设计步骤：需求 → 真值表 → 表达式 → 化简 → 逻辑图

常见组合电路：

  • 加法器（半加器、全加器）
  • 译码器、编码器
  • 数据选择器、比较器
例题 半加器
半加器输入 1 和 1，输出 S 和 C 分别是多少？
1半加器实现一位二进制加法：S = A⊕B，C = A·B。
2S = 1⊕1 = 0（不同出 1，相同出 0）。
3C = 1·1 = 1（产生进位）。
4即 1 + 1 = 10（二进制），本位上 0，进位 1。
1半加器的和 S 等于什么？
